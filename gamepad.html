③ iPad Chrome 操作步驟

  1. 在 iPad「設定 → 藍牙」配對 IINE 手把；回到本頁按手把測試，確認 Gamepad API 顯示連線且實體按鍵有亮起索引。
  2. 按「複製外部載入書籤」，在 Chrome 將目前頁面加入書籤；到「⋯ → 書籤 → 編輯」，把書籤網址替換成剛複製的 javascript:…，名稱可設「手把游標」。
  3. 開啟 ahaboard.ai，從 Chrome 書籤執行「手把游標」。左搖桿移動、A 點擊、B 或 X 叫出頁面自訂右鍵選單、右搖桿上下或十字鍵上下捲動；按 Esc 或再次執行書籤停止。

限制與備用方案

這是頁面內的合成 DOM 事件，不是真正的系統滑鼠。網站若只接受可信任實體事件、需要拖曳/觸控，或瀏覽器把手把 API 對 Chrome 隱藏，網頁腳本無法解除這些限制。

如果目標站 CSP 只是不允許從 GitHub 載入外部 script，可試「單檔備用書籤」。若 CSP 連書籤的 JavaScript 執行也封鎖，兩種 bookmarklet 都不能繞過；需由網站管理方調整 CSP 或改用原生輔助輸入設備。

GitHub Pages 部署：把本資料夾的檔案放到 repository 根目錄，在 GitHub repository 的 Settings → Pages 選擇部署來源。開啟發布後以 HTTPS 網址使用此頁。

手把輸入只在目前分頁讀取；書籤腳本不會把手把狀態傳送至其他伺服器。
